# 品牌与组织同步模块阶段记录

## 品牌资产

- 浏览器入口使用本地 CRRC 长客标识；SVG 由用户提供的 PNG 描摹为纯路径，没有字体或内嵌位图。
- 当前 SVG 是待品牌责任人审核的矢量重绘草稿，不是企业正式矢量源稿。
- 源码 Logo 变更已提交，但实际容器当时运行的静态文件来自较早镜像；需要源码依赖可用后重新构建镜像并在浏览器验证，才能验收运行时品牌。

## 产品命名迁移

本仓库正在执行完整的产品标识迁移；迁移尚未完成。产品入口与少量资产已更新，Python 根包、目录、导入路径、CLI、环境变量、数据库持久化值、序列化类型和大量源码文档仍有旧标识。暂时保留这些字符串是兼容基线事实，不代表已批准其作为长期产品接口。

改名前逐类更新 [`identifier-inventory.csv`](identifier-inventory.csv)，保留逐项迁移映射和外部契约依据。禁止盲目替换第三方依赖名、许可证归属、上游历史记录和外部协议。持久化 Flow 类路径及数据库引用要在副本中演练迁移和恢复，再讨论生产变更。

## 组织同步模块当前行为

代码位于 `packages/dbgpt-serve/src/dbgpt_serve/organization_sync/`。目前可以注入目录读取适配器，并校验外部 ID 唯一性及组织/部门/用户引用完整性。预览只汇总数量，不写数据库、不更改账号状态、不分配角色。

真实目录协议、平台侧持久化、受控提交、事务、审批、脱敏审计、停用撤权传播和定时任务尚未实现。生产必须默认禁用模拟目录。适配器预留不能当作已完成的组织同步能力或成员授权。
