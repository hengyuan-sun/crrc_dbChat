# 企业组织信息同步扩展点

此模块为后续对接长客内网组织目录、统一身份平台或人力资源系统预留稳定的数据契约，包含组织、部门、用户快照、适配器协议以及只读校验/预览服务。

## 当前行为

- `OrganizationDirectoryAdapter` 由企业内网适配器实现，读取完整组织快照。
- `OrganizationSyncService.read_and_validate()` 检查外部 ID 唯一性和组织/部门关联完整性。
- `OrganizationSyncService.preview()` 只提供数量预览，不创建、停用或授权用户，也不写数据库。
- 当前没有默认目录连接器、组织数据表、管理员 API 或自动同步任务，因此不会凭空模拟组织信息同步成功。

## 后续接入契约

1. 由企业确认目录协议、稳定字段、禁用用户处置方式和权威部门映射。
2. 实现目录适配器和受控的 `OrganizationStore`，凭据从内网密钥管理系统引用。
3. 加入人工预览/审批、幂等批次、审计记录和可回滚事务后，再挂载管理 API 与定时任务。
4. 身份认证及 workspace 授权必须在服务端校验；目录同步不能直接赋予平台管理员角色。
